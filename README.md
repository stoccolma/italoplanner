# ItaloPlanner — landing page

The public page for **ItaloPlanner**, an iOS travel companion for Italy.
Served by GitHub Pages from this repository's root.

The app itself is in development and is not yet on the App Store. This page
exists so there is somewhere to point at in the meantime.

Screenshots under `img/` are captured from the iOS Simulator and resized with
`sips -Z 780`. Re-capture them when the interface changes.
